# Final Report

The final deliverable is a **single nine-page A4 report** created in Canva and exported as a PDF. The Canva design is the editable master; the PDF is the submission copy.

**Canva editable design:** https://www.canva.com/d/QaO7S9C3HdCNRsj

## Contents

1. Cover
2. Executive summary
3. Scope, methodology and limitations
4. Browser evidence and HTTPS trust observation
5. Findings overview
6. Detailed browser-security-header findings
7. Detailed resource and cookie findings
8. Server and content-type header findings
9. Conclusion, unconfirmed observations and references

Each candidate finding explains the technical observation in plain English, the potential business impact, proposed priority and recommended remediation. OWASP Cheat Sheets and MDN are referenced where relevant.

**PDF location:** `report/FUTURE_CS_01_Vulnerability_Assessment_Report.pdf`
