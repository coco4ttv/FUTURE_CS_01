# Tools Used

| Tool | Permitted use | Restrictions |
|---|---|---|
| Chrome / DevTools | Manual public-page review, Network response headers and screenshots | No credential entry or form submission |
| OpenSSL | Read-only TLS certificate inspection, if HTTPS endpoint responds | No intrusive probing |
| OWASP ZAP | Passive observation of manually browsed public pages | Passive mode only; no spider, active scan, fuzzing or attack |
| Canva / PDF export | Formatting the final report | Ensure screenshots and claims match the evidence |

Nmap is intentionally excluded from this assessment. Do not run port or service scans under this scope.
