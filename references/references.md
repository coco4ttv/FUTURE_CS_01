# References

- [OWASP ZAP — AltoroJ / Testfire](https://www.zaproxy.org/docs/testapps/altoroj/) — information about the AltoroJ sample application and the availability limitations of the online demo.
- [HCL Altoro Mutual status check](https://www.testfire.net/status_check.jsp) — the application's status endpoint.
- [HCL AltoroJ project on GitHub](https://github.com/HCL-TECH-SOFTWARE/AltoroJ) — source project for the demonstration application.
- [OWASP Secure Headers Project](https://owasp.org/www-project-secure-headers/) — reference I used for understanding HTTP security response headers.
- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) — general web application testing reference.

I used external availability information as context only. My own dated browser captures remain the evidence for the tests I performed.
